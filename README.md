# Cotempo


## 📁 주요 프로젝트 구조

```text
src/
├── api/                    # 서버 API 요청 및 통신 설정
├── assets/                 # 이미지, 로고, SVG 등 정적 파일
├── auth/                   # 인증 상태 관리 및 접근 제어
├── components/
│   ├── common/             # 전역 공통 컴포넌트
│   ├── home/               # 홈 및 캘린더 관련 컴포넌트
│   ├── icons/              # 아이콘 컴포넌트
│   ├── modal/              # 모달 및 입력 컴포넌트
│   └── mypage/             # 마이페이지 관련 컴포넌트
├── pages/                  # 라우팅 단위 페이지
├── utils/                  # 공통 유틸리티 함수
├── App.jsx                 # 라우팅 및 애플리케이션 구성
├── main.jsx                # 애플리케이션 진입점
└── index.css               # 전역 스타일(tailwind css)
```
